Frost Window

30 years of daily lows, a frost forecast you can count on, and a four-line "go outside" plan written by Gemma running on a laptop.

Numbers: Open-Meteo historical archive (CC BY 4.0), last 30 years, low at or below 0 °C. Plans: Gemma 3 4B via Ollama, generated locally when this page was built. Run it for your own town: source on GitHub.
